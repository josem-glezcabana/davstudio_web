# DAVSTUDIO

GL
Este é un proxecto para o desarrollo dunha página web para o estudio de interiorismo DAVSTUDIO. O obxectivo é crear unha páxina web onde se poderá mostrar de cara ao público todo o que pode ofrecer este estudio de interiorismo, para conocer o seu enfoque vanguardista á hora de facer creacións para a mellora de espazos tanto privados como públicos.

ES
Este es un proyecto para el desarrollo de una página web para el estudio de interiorismo DAVSTUDIO. El objetivo es crear una página web donde se pueda mostrar al público todo lo que este estudio de interiorismo puede ofrecer, para conocer su enfoque vanguardista a la hora de realizar creaciones para la mejora de espacios tanto privados como públicos.

EN
This is a project for the development of a website for the DAVSTUDIO interior design studio. The goal is to create a web page where everything this interior design studio can offer can be shown to the public, to learn about its avant-garde approach when making creations for the improvement of both private and public spaces.
